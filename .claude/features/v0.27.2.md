**Date:** 2026-10-24

### Fixed

- **После закрытия Kino «висел в трее» без окна.** Значок в скрытых значках не открывал меню, повторный запуск с ярлыка ничего не давал — помогало только снять процесс.
  - Найдено наблюдением за установленным 0.27.1: окно не ушло в трей, а закрылось по-настоящему, потому что в этот момент ничего не качалось и не раздавалось. Затем Kino начал выходить и завис посередине: процесс жив, окон и сетевых соединений нет.
  - Воспроизведено на релизной сборке: зависание бывает, только если в этом запуске показывалось видео. mpv останавливался уже после того, как окно, в котором он рисует, уничтожено. Само завершение процесса (выгрузка DLL видеодрайвера) после этого висит навсегда, даже `exit`.
  - Теперь при выходе (крестик, когда ничего не качается, или «Выйти» в трее):
    1. окно сразу прячется;
    2. в отдельном потоке, пока главный поток работает, mpv сохраняет позицию и останавливается, Kino ждёт этого до 4 с;
    3. торренты сохраняют состояние и останавливаются (до 6 с);
    4. значок убирается из трея;
    5. процесс завершается сам, минуя зависающую выгрузку DLL.
  - Для любого другого пути выхода есть предел: через 8 с процесс завершается в любом случае.
  - Процессы WebView2 закрываются вместе с Kino, позиция просмотра сохраняется.
- **Возврат из трея** (раздача идёт, Kino в трее): проверен на релизной сборке с видео — клик по значку возвращает окно с прежним экраном.

### Changed

- **Двойной клик по видео больше не включает и не выключает полный экран.** Полный экран — клавиша F и кнопка в панели; Escape — выход. Клик по видео ставит паузу, быстрый второй клик возвращает как было. В мини-плеере двойной клик по-прежнему разворачивает окно.
- Тестовый флаг `KINO_TEST_TRAY`: трей и в тестовом режиме, для проверки возврата из трея.
