**Date:** 2026-10-23

### Added

- Монорепозиторий Kino 2 на Bun workspaces: `apps/*` (приложение на Tauri — следующий этап) и `packages/*`
- Общий `tsconfig.base.json` (TypeScript 7, строгий режим, `noUncheckedIndexedAccess`, `verbatimModuleSyntax`)
- `@kino/ui` — своя UI-библиотека в направлении «Проектор»:
  - `tokens.css` — единственный источник токенов: цвета (палитра Tailwind отключена), шрифты, размеры текста, радиусы, тени, кривые и длительности анимаций
  - `base.css` — поведение нативного приложения вместо веб-страницы: без выделения интерфейса, без курсора-руки, без системных полос прокрутки, без браузерной обводки фокуса, без перетаскивания картинок, с учётом `prefers-reduced-motion`
  - шрифты Unbounded, Golos Text и JetBrains Mono встроены через fontsource (латиница и кириллица), без запросов в сеть
  - `installDesktopGuards()` — отключает браузерное поведение WebView2: F5, Ctrl+R/P/F/U/S/N/T, масштаб клавишами и колесом, Alt+←/→, системное контекстное меню вне полей ввода, автопрокрутку средней кнопкой, перетаскивание картинок и переход по брошенному файлу. F12 — только с `allowDevtools`
  - набор из 34 SVG-иконок на сетке 24 (`createIcon`), декоративные по умолчанию, с `label` — доступные
  - компоненты на react-aria: `Button` (primary, secondary, outline, ghost, danger; sm/md/lg), `IconButton` (ghost, overlay, solid; обязательная подпись, состояние «включено»), `Switch`, `SegmentedControl`, `Slider` (своя дорожка и ползунок вместо `input[type=range]`), `Kbd`, `ScrollArea` (своя полоса прокрутки с перетаскиванием), `Logo` (`kin●`, три размера)
  - `cn` и `tv`, настроенные на имена наших токенов
  - витрина компонентов (`bun run ui`, порт 5180)
  - 30 unit-тестов: нажатия мышью и с клавиатуры, кольцо фокуса только с клавиатуры, отключённые состояния, радиогруппа на стрелках, шаг и границы слайдера, блокировка браузерных сочетаний
- `design/prototype.html` — интерактивный HTML-прототип всех экранов (главная с историей, сериал, плеер, настройки, первый запуск) как дизайн-референс
- `.claude/CLAUDE.md` — правила проекта Kino 2: стек, архитектура, правила UI-библиотеки, процесс
