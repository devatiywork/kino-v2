### Added

- **`.claude/SPEC.md` — техническое задание Kino 2.** Kino теперь видеоплеер и торрент-клиент в одном окне, две независимые части:
  - плеер — всё из Kino 1 плюс главная с историей просмотра, память дорожек по сериалу, «Освободить место» для досмотренных сезонов
  - торренты — качает что угодно (сериалы, игры, программы), категории (базовые: Сериалы, Игры, Программы; свои можно создавать), **постоянный архив всех торрентов** вместе с самими `.torrent`, чтобы скачать снова в один клик, не ища раздачу
  - удаление торрента — три разных действия: убрать из загрузок, удалить с файлами (запись остаётся), удалить из архива (только с подтверждением)
  - связь частей необязательная: кнопка «Смотреть» у торрента с видео и «Скачать снова» у сериала, чьи файлы удалены
  - раздел «Предложения на согласование» — то, что не делать без подтверждения (пропуск заставки, карточка «Далее», категория «Фильмы», последовательная загрузка, импорт из qBittorrent и др.)
