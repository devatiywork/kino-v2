**Date:** 2026-10-24

### Added

- **Резервная копия архива** (ТЗ 4.4) — кнопка «Резервная копия» на вкладке «Архив».
  - «Сохранить копию архива…»: весь архив в один файл `kino-archive-ГГГГ-ММ-ДД.json`:
    - категории (с их папками);
    - для каждой записи — название, категория, папка, страница раздачи, даты добавления и завершения, выбранные файлы, отданное, «файлы удалены»;
    - сам `.torrent` внутри (base64).
  - Файл пишется рядом и подменяет старый только целиком: оборванная запись не оставит половину копии.
  - «Восстановить из копии…» на другом компьютере или после переустановки:
    - добавляется только то, чего в архиве нет (по хешу), существующее не меняется — одну копию можно восстанавливать сколько угодно раз;
    - категории сопоставляются по имени без учёта регистра, недостающие создаются с их папками;
    - записи встают в архив со своими датами и рейтингом, в загрузки не попадают;
    - Kino сообщает, сколько добавлено, сколько уже было, и какие записи не прочитались (без `.torrent`).
  - Чужой JSON или копия из более новой версии Kino отклоняются с понятной ошибкой.
- **Фильтр архива по датам** (ТЗ 4.4): «Когда добавлен» — за всё время, неделю, месяц, 3 месяца, год, а также каждый год, который есть в архиве. Работает вместе с поиском и фильтром по категориям. Если за выбранное время ничего нет — «За это время в архив ничего не добавлялось».
- Ядро:
  - `torrent/backup.rs` — `export_archive`, `restore_archive`;
  - `TorrentStore::insert_archived`;
  - команды `torrent_export_archive`, `torrent_restore_archive`;
  - зависимость `base64` 0.23 (та же версия, что уже в дереве).
- Интерфейс:
  - фича `archive-backup` (`ArchiveBackupMenu`);
  - `entities/torrent/lib/period.ts` (`matchesPeriod`, `periodOptions`), `period` в `downloadsView`;
  - `appIpc.pickBackupTarget` / `pickBackupFile`;
  - разрешение `dialog:allow-save` для системного «Сохранить как».
