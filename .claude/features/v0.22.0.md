**Date:** 2026-10-24

### Added

- **Проверка обновлений** (ТЗ 6 «Система», ТЗ 4.7) через GitHub Releases репозитория `devatiywork/kino-v2`:
  - выключена по умолчанию: Kino ходит в сеть за этим, только когда её включат;
  - включённая проверка срабатывает через 20 секунд после запуска, потом раз в день;
  - о новой версии Kino говорит один раз: уведомление висит до закрытия, «Что нового» открывает страницу версии в браузере. Номер версии запоминается — о ней больше не напомнят;
  - «Система» → «Проверять обновления»: переключатель и «Проверить сейчас». Строка сообщает «Вышла Kino 0.23.0» (с кнопкой «Открыть страницу версии»), «У вас последняя версия» или «Не удалось проверить: …»;
  - ничего не скачивается и не ставится само.
  - Ядро:
    - `updates.rs`: версии сравниваются числами (`0.100.0` новее `0.99.9`); черновики и пререлизы не считаются; GitHub получает `User-Agent: Kino/<версия>`;
    - `reqwest` — тот же клиент и TLS, что у движка торрентов.
  - Найденная версия ждёт в ядре (`PendingUpdate`), интерфейс забирает её при старте и по событию `app://update`. Так уведомление не теряется, если проверка закончилась раньше, чем открылась страница, и не показывается дважды.
- **Значок Kino** — «Объектив»: кольцо из логотипа и «плей» на графите тёмной темы.
  - Для 16–32 px отдельный рисунок: квадрат во всю клетку, кольцо толще, «плей» крупнее, иначе на панели задач и в трее он расплывается.
  - Исходники — `apps/desktop/src-tauri/icons/source/icon.svg` и `icon-small.svg`. `bun scripts/make-icons.ts` собирает `icon.ico` (16–256 px) и `icon.png` (512 px) через CLI Tauri.
  - Значок у exe, окна, панели задач, трея и установщика.

### Changed

- `KINO_UPDATES_URL` — адрес релизов вместо GitHub, для автотестов. При нём первая проверка идёт через секунду, а при `KINO_TEST_OFFLINE` без него Kino не обращается к GitHub совсем.
