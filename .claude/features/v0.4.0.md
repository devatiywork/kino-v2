**Date:** 2026-10-23

### Added

Экраны торрентов в дизайн-референсе `design/prototype.html` — по ТЗ, разделы 4.1–4.5.

- **Навигация.** В заголовке окна раздел «Загрузки» со значком числа активных закачек; на других экранах (кроме плеера) — чип общей скорости ↓, по клику открывает загрузки
- **Загрузки** — вкладки «Загрузки · Архив · Трекеры», общая скорость ↓/↑, «Пауза всех», «Magnet-ссылка», «Добавить торрент» (выбор `.torrent` с диска):
  - фильтр по категориям с количеством; «+ Категория» создаёт новую; правый клик по категории — переименовать, папка по умолчанию, удалить (её торренты уходят в «Без категории»)
  - строки торрентов: категория, файлы, размер, сиды и пиры, прогресс, статус (загрузка, раздача, пауза, в очереди), осталось времени или рейтинг, скорость ↓/↑; прогресс и скорость живые
  - «Смотреть» у сериала, который уже частично скачан, — открывает плеер
  - подробности снизу: «Файлы» (галочки, размер, прогресс файла) и «Сведения» (хеш, папка, категория, дата, страница раздачи, отдано)
  - меню действий (кнопка «…» и правый клик): открыть папку, скопировать magnet, страница раздачи, смена категории, «Убрать из загрузок», «Удалить с файлами» (с подтверждением)
- **Архив** — все торренты, которые когда-либо добавлялись:
  - поиск по названию и файлам, сортировка «Новые сначала / По имени», группы по месяцам
  - у записи: категория, размер, файлы, дата, ссылка на раздачу (или «только magnet-ссылка» / «страница не указана»), статус («Файлы на диске», «Файлы удалены», «Загрузка», …)
  - действия: «Скачать снова», «В загрузках», «Открыть папку», указать страницу раздачи, смена категории, «Удалить из архива» (с подтверждением)
  - «Резервная копия» и «Импорт»
- **Трекеры** — встроенное окно:
  - закладки (Рутрекер, RuTor) и «Добавить трекер»
  - панель: назад, вперёд, обновить, адрес, «Изолировано от Kino», «Открыть в браузере»
  - заглушка сайта: результаты поиска и страница раздачи с кнопками «Скачать .torrent» и «Магнет-ссылка»
  - нажатие перехватывается: плашка «Kino перехватил .torrent — в „Загрузки“ Windows ничего не сохранено» и сразу окно добавления
  - «Открыть страницу раздачи» из архива открывает её во вкладке «Трекеры»
- **Окно добавления торрента**:
  - откуда пришёл (файл .torrent, magnet-ссылка, перехвачено на трекере, из архива)
  - название, размер, число файлов, хеш
  - категория — обязательна: по разделу трекера или последняя использованная; «Новая категория» прямо в окне, папка подставляется сама
  - папка (по умолчанию — папка категории), страница раздачи (подставляется с трекера), «Начать сразу»
  - файлы с галочками и «выбрать все»
  - для magnet-ссылки: название из ссылки, «Получаем список файлов от участников раздачи…», потом список
  - **«Уже в архиве»**: тот же хеш — плашка с категорией, датой и статусом, кнопка «Скачать снова» / «Открыть в загрузках» / «Показать в архиве», дубль не создаётся
- Перетаскивание `.torrent` в окно открывает окно добавления, видео — как раньше
- Панель прототипа: «Загрузки», «Архив», «Трекеры», «Добавление торрента», «Добавление: уже в архиве», «Добавление magnet-ссылки»
- Иконки: стрелки ↓/↑, magnet, обновить, внешняя ссылка, архив, категории (сериалы, игры, программы, метка), «…», замок, копировать, изменить
