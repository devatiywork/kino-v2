**Date:** 2026-10-24

### Added

- **Экран «Настройки»** (ТЗ 6), открывается кнопкой справа в заголовке. Слева меню разделов: при прокрутке подсвечивается текущий, клик прокручивает к разделу. Все изменения применяются сразу и сохраняются, кнопки «Сохранить» нет
  - **Внешний вид:** оформление (тёмное / светлое / как в Windows), акцентный цвет (5 образцов), язык (русский / English). Тема и язык меняются без перезапуска; плеер всегда тёмный и получает тёмный оттенок акцента
  - **Воспроизведение:** продолжать с места остановки; следующая серия автоматически (та же настройка, что переключатель в панели серий); скорость и громкость по умолчанию — с них начинается каждый запуск; аппаратное декодирование (`hwdec` auto-safe / no, меняется на лету)
  - **Озвучка и субтитры:**
    - предпочитаемая озвучка: русская или оригинал;
    - субтитры при русской озвучке: выкл, форсированные (только надписи) или полные;
    - размер субтитров (`sub-scale` 0.85 / 1 / 1.2) и положение (`sub-pos` 100 / 95 / 90).

    Для сериала важнее то, что выбрано в его прошлых сериях: память дорожек срабатывает первой
  - **Библиотека и история:** вести историю; порог «просмотрено» (85 / 90 / 95%); папки сериалов (те же, что на экране «Сериалы», с добавлением и удалением); «Очистить историю» с подтверждением
  - **Горячие клавиши:** таблица действий плеера. Клик по клавише, затем новая клавиша. Занятая клавиша меняется местами с прежней, и тост об этом говорит, так что ни одно действие не остаётся без клавиши. Escape (выход из полного экрана) не меняется. Tab и сочетания с Ctrl / Alt / Win не назначаются. Есть «Вернуть стандартные». Подсказки кнопок плеера показывают новые клавиши
  - **Система:** «Не давать компьютеру засыпать» — пока идёт видео, Kino держит запрос питания Windows (экран не гаснет, сон не начинается); на паузе и в конце файла запрос снимается. Здесь же «Сбросить настройки» с подтверждением: история, папки и память дорожек остаются
- Ядро: модуль `settings`
  - Все настройки — одна типизированная структура, хранится одной JSON-строкой в `app_settings`
  - Испорченное или устаревшее значение заменяется своим значением по умолчанию, остальные настройки сохраняются
  - Команды `settings_get`, `settings_update` (частичное изменение: неизвестные ключи и неверные значения отклоняются, значения между допустимыми округляются к ближайшему) и `settings_reset`; событие `settings://changed`
- Ядро: выбор дорожек по умолчанию (`player/track_defaults.rs`) для файлов, по которым ничего не запомнено
  - Русская дорожка определяется по языку `ru` / `rus` или по кириллице в названии, если язык не указан
  - Оригинал — первая дорожка с известным языком, кроме русского
  - Форсированные субтитры — по флагу forced или по словам «надписи», «forced», «signs» в названии
- Ядро: `app_clear_history` — удаляет просмотры, места остановки, кадры и память дорожек
  - Папки медиатеки и их серии остаются
  - Файлы, которые были только открыты, забываются
  - Открытый сейчас файл начинает новый просмотр
- Миграция БД 3: переключатель автовоспроизведения из версии 0.9 (`player.autoplay`) переносится в новые настройки
- UI-библиотека (0.6.0):
  - `SwatchPicker` — выбор цвета из набора, радиогруппа со стрелками и подсказками;
  - `KeyRecorder` — запись клавиши: Escape отменяет, модификаторы без клавиши не считаются, уход фокуса отменяет ожидание, пока ждём — клавиши не доходят до страницы.

  Оба компонента с тестами и в витрине; в шапке витрины выбор акцента
- Набор акцентов в `tokens.css`: оранжевый (по умолчанию), золотой, лайм, бирюзовый, сиреневый. У каждого свой оттенок для тёмной темы (тёмный текст на акценте) и для светлой (белый текст, контраст не ниже 4.5:1 — проверено расчётом)
- Переводы `settings.json` (ru, en), строка «Отмена» в `common.json`
- Тесты:
  - Rust — 61 (было 46): настройки (умолчания, частичные изменения, отказ на неверные значения, восстановление после порчи, хранение между запусками), миграция, порог «просмотрено», работа без истории, очистка истории, выбор дорожек по умолчанию;
  - Vitest — 84 + 82 (было 60 + 75): клавиши (переназначение, обмен, запреты, подписи), хранилище настроек, оформление, таблица клавиш, очистка истории, экран настроек, SwatchPicker, KeyRecorder;
  - E2E — 15 (было 11): оформление, акцент и язык меняются сразу, переживают перезапуск и сбрасываются; без «Продолжать с места» файл начинается сначала; переназначенная клавиша сохраняется и работает в плеере; очистка истории только после подтверждения, папки остаются.

### Changed

- Автовоспроизведение больше не хранится в состоянии плеера: команда `player_set_autoplay` и поле `autoplay` снимка убраны. Переключатель в панели серий (фича `toggle-autoplay`) меняет настройку `autoplay`
- `applyAccent` принимает название акцента из набора (`ACCENTS`) и ставит `data-accent` на корень вместо произвольного цвета `--kino-accent-custom`. Каждый элемент с `data-theme` берёт оттенок своей темы, поэтому плеер поверх светлой темы получает тёмный вариант
- Тема и язык загружаются из ядра до первого рендера (`loadSettings` в `main.tsx`), чтобы при запуске ничего не мигало
- Клавиши плеера берутся из настроек в момент нажатия; `DEFAULT_KEYMAP` строится из `DEFAULT_HOTKEYS` (сущность `settings`)
- Если «Продолжать с места остановки» выключено, кнопка на главной говорит «Смотреть сначала», а не «Продолжить с 0:23»
- `Library::is_watched` берёт порог из настроек. Без истории `register` не трогает `last_played_at`, а сессия не пишет позиции, просмотры и кадры
- Громкость, скорость, размер и положение субтитров, `hwdec` задаются mpv при запуске из настроек; `KINO_TEST_VOLUME` по-прежнему главнее в debug-сборке
