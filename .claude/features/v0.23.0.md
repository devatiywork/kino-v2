**Date:** 2026-10-24

### Added

- **Блокировка рекламы в окне трекеров** (ТЗ 4.5), включена по умолчанию:
  - движок — `adblock` от Brave (MPL-2.0), списки — RU AdList + EasyList (113 тыс. строк). Снимок списков встроен в Kino (`src-tauri/filters/`), сам Kino за ними в сеть не ходит (ТЗ 4.7). Обновить перед выпуском: `bun scripts/fetch-filters.ts`;
  - **запросы:** каждый запрос страницы, её фреймов и воркеров проходит через `WebResourceRequested` WebView2, рекламный получает пустой ответ 403. Собственная навигация страницы (адрес, который открывают, и её сайт) не блокируется никогда;
  - **оформление:** когда документ разобран, страница получает стиль, скрывающий рекламные блоки по правилам её сайта. Через 2,5 секунды Kino смотрит ещё раз — на то, что добавили скрипты. Общие правила применяются к классам и id, которые есть на странице. Kino читает их как результат `ExecuteScript`: у страницы нет способа обратиться к Kino;
  - **щит в панели браузера** — сколько рекламных запросов остановлено на этой странице. Нажатие выключает или включает блокировку и перезагружает страницу. То же — «Загрузки» → «Поведение» → «Блокировать рекламу на трекерах»;
  - движок собирается в фоне при запуске Kino: список разбирается быстрее секунды. Страница, загрузившаяся раньше, чем движок готов, получает стиль скрытия, как только он готов (полный прогон E2E поймал эту гонку: правило сайта не применялось);
  - проверено на настоящих трекерах: на главной rutracker исчезли баннер в шапке, боковые рекламные блоки и баннер под ними, форум цел; на rutor остановлены два рекламных запроса, страница не изменилась.
- `IconShield` в `@kino/ui` (0.11.0).

### Fixed

- **Из окна трекеров открывается и сохраняется только торрент.** Раньше любая загрузка, кроме `.torrent` по имени, молча уходила в «Загрузки» Windows (например, `setup.exe` из рекламы), а содержимое `.torrent` проверялось только в окне добавления. Теперь:
  - файл с явно другим расширением (`.exe`, `.zip`, `.mkv`…) не скачивается совсем;
  - файл с `.torrent` в имени или ссылке, а также файл, по имени которого ничего не понять (`dl.php`, `download`), скачивается в папку Kino. Kino проверяет содержимое: настоящий торрент — разобранный bencode с описанием `info`, до 32 МБ;
  - торрент открывается в окне добавления (из `dl.php` он становится `.torrent`), всё остальное удаляется — в том числе страница «Войдите», выданная под именем `.torrent`;
  - в строке над страницей: «„setup.exe“ не скачан: здесь Kino сохраняет только .torrent. Нужен этот файл — „Открыть в браузере“».
- Kino никогда не запускает скачанные файлы: торрент только читается.
