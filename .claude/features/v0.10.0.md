**Date:** 2026-10-24

### Added

- E2E-тесты настоящего приложения: Playwright подключается к WebView2 через CDP (`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=N`) и управляет debug-сборкой Kino с настоящим libmpv. Команда — `bun run e2e` (из корня или `apps/desktop`)
  - `e2e/kino.ts` — запуск `kino-desktop.exe` (с файлом в командной строке, как из Проводника, или без), подключение по CDP, `invoke` команд ядра со страницы, снимок плеера. У каждого запуска своя временная папка данных и свой профиль WebView2, после теста всё закрывается и удаляется. Папку можно передать следующему запуску — так проверяется перезапуск
  - `e2e/global-setup.ts` — проверяет, что тестовые субтитры не испорчены, и собирает debug-ядро (`cargo build`, ничего не делает, если всё собрано). Vite поднимается сам (`webServer`, порт 5181, переиспользуется)
  - Плеер (4 теста): запуск с файлом из командной строки; пауза, перемотка и полноэкранный режим с клавиатуры; клик по полосе перемотки; переключение озвучки и субтитров без перезагрузки видео
  - История (2 теста): главная предлагает «Продолжить с 0:2x», файл продолжается с места с плашкой «Продолжено с…», «Начать сначала» возвращает в начало; история переживает перезапуск Kino
  - Сериалы (5 тестов): папка библиотеки превращается в сериал с сезонами и сериями по порядку; автовоспроизведение следующей серии с остановкой в конце сезона; N/P переходят между сезонами; выбранные озвучка и субтитры переносятся на следующую серию; панель серий и выключение автовоспроизведения
- Тестовые ролики `e2e/fixtures/media` (около 1,2 МБ, сделаны mpv из сгенерированной картинки и тона — никаких личных файлов): сериал `Kino.Test` из двух сезонов с внешней английской озвучкой `.mka` и русскими субтитрами `.srt` у первых серий, фильм `Film.2014` на 75 с с русскими субтитрами **в Windows-1251**. Скрипт `e2e/fixtures/make-media.ps1 -Mpv <mpv.exe>` пересоздаёт их
- Переменные ядра для тестов:
  - `KINO_DATA_DIR` — папка для `kino.db` и кадров вместо `%APPDATA%\local.kino.app`, чтобы тесты не трогали настоящую историю
  - `KINO_TEST_VOLUME` (только debug) — громкость mpv с первого кадра
  - `KINO_TEST_MONITOR` (только debug) — монитор по разрешению, например `1920x1080`: окно открывается по центру этого монитора и не забирает фокус (ни окно, ни WebView). Если такого монитора нет — основной монитор, тоже без фокуса
- Тесты не мешают работать: громкость 1%, окно на Full HD-мониторе, фокус остаётся там, где был. Другие значения — `KINO_E2E_VOLUME`, `KINO_E2E_MONITOR`

### Changed

- Главное окно создаётся в `setup` из той же конфигурации (`"create": false` в `tauri.conf.json`, затем `WebviewWindowBuilder::from_config`), чтобы тесты могли поставить его на нужный монитор. Для обычного запуска ничего не изменилось: 1280×800 по центру основного монитора
- `typecheck` в `apps/desktop` проверяет и E2E (`e2e/tsconfig.json`)

### Fixed

- Тестовые субтитры показывались «кракозябрами» (`РўРµСЃС‚РѕРІС‹Рµ…`). Виноват был не плеер: Windows PowerShell 5.1 читает скрипт без BOM как ANSI (cp1251), и кириллица из `make-media.ps1` попадала в `.srt` уже испорченной, а Kino честно показывал то, что было в файле. Теперь в скрипте только ASCII, субтитры копируются байт в байт из шаблонов `subtitles.ru.srt` (UTF-8) и `subtitles-cp1251.srt` (перекодируется в Windows-1251), а `global-setup` останавливает прогон, если текст в роликах испорчен
- Проверено, что настоящие русские `.srt` в Windows-1251 читаются правильно: mpv определяет кодировку сам (uchardet: «detected charset as WINDOWS-1251»), настраивать `sub-codepage` не нужно
