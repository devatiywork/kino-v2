**Date:** 2026-10-24

### Added

Второй этап приложения: база SQLite, история просмотра, продолжение с места и память дорожек для сериала (ТЗ 3.2, 3.3, 7).

- **База** (`src-tauri/src/db.rs`): один файл `%APPDATA%\local.kino.app\kino.db`, миграции по `PRAGMA user_version`, WAL. Таблицы плеера — `player_files` (файл, сериал, сезон, серия, длительность, позиция, «просмотрено», когда смотрели, есть ли кадр), `player_views` (просмотры для истории), `player_series_tracks` (память дорожек). Торренты получат свои таблицы `torrent_*` и не будут ссылаться на плеер
- **Сериалы по именам файлов** (`library/episode.rs`): `S02E05`, `s1e12`, `2x05` (но не `1920x1080`), «Серия 5», «05 серия», «Episode 3»; название сериала — текст до метки серии без точек, тегов `[группа]` и года. Без названия — папка сериала, а папка «1 Сезон» / «Season 01» / «S02» пропускается. Ключ сериала общий для всех его серий в любых папках
- **Позиция и история**: ядро сохраняет позицию раз в 5 секунд, на паузе, в конце файла и при закрытии окна; каждый просмотр — строка истории (начало, конец, где остановились). Открытие файла и тут же другой не попадает в историю (меньше 3 секунд)
- **Продолжение с места**: файл открывается с сохранённой позиции, если она больше 10 секунд, до конца больше 30 секунд и файл не досмотрен; досмотренное (90%) начинается сначала. В плеере на 6 секунд — «Продолжено с 23:14 · Начать сначала»
- **Память дорожек для сериала**: выбор озвучки и субтитров в плеере запоминается для сериала и применяется к следующим сериям, когда известен список дорожек нового файла
  - подбор только по языку и названию, никогда по номеру; в названии не учитываются кодек, каналы и битрейт («DD 5.1 @ 640 kbps (AVO Goblin)» = «AC3 5.1 @ 448 kbps (AVO Goblin)»), `ru` = `rus`
  - дорожка без названия и языка (простой mp4) подбирается как такая же безымянная — встроенная или внешняя
  - озвучки нет — включается первая и уведомление «Озвучка «LostFilm» не найдена, выбрана: English»; субтитров нет — выключаются и уведомление
  - «выключено» тоже запоминается
- **Кадры для карточек**: на 15-й секунде и на каждой паузе mpv сохраняет кадр без субтитров в `thumbs\<id>.jpg`; страница показывает его через asset-протокол Tauri (доступ только к папке кадров)
- **Главная** по прототипу: «Продолжить» — кадр остановки, сериал, «Сезон 1 · Серия 5», имя файла, прогресс, «осталось», «Продолжить с 23:14»; справа — история по дням; ниже «Не досмотрено» — карточки с кадром, серией, «ещё 23 мин» и полоской. Из сериала предлагается последняя открытая серия; если её досмотрели — сериал не предлагается (следующая серия — с этапом медиатеки). Пока ничего не смотрели — экран первого запуска
- **История** — отдельный экран: все просмотры по дням («Сегодня», «Вчера», «20 октября», с годом для прошлых лет), время, кадр, сериал и серия, «досмотрено» или «остановились на 23:14»; клик открывает файл с места. Удалённый файл — пометка и предупреждение вместо открытия
- В плеере над видео — «Сериал · Сезон 1 · Серия 2» вместо имени файла
- Главная и история обновляются сами по событию ядра `library://changed`
- **@kino/ui 0.5.0**: `Pressable` — нажимаемая поверхность без своего вида для карточек и строк (клавиатура, фокус, data-состояния), с тестами и в витрине
- Тесты: Rust — 32 (миграции, разбор серий, подбор дорожек, позиция и «просмотрено», «Продолжить», история, память дорожек на базе в памяти); Vitest — 50 в приложении (подписи, дни, синхронизация библиотеки, открытие из истории, плашка продолжения, главная) и 75 в UI-библиотеке
- Проверено в запущенном приложении на тестовом «сериале» из трёх серий: позиция и кадр сохраняются, главная и история показывают просмотры, вторая серия получила выбранные в первой дорожки, третья — уведомление о ненайденной озвучке, повторное открытие продолжает с места

### Fixed

- В плеере не было названия файла, а позиция не сохранялась бы: mpv присылает новый путь раньше события `StartFile`, и обработчик стирал его. Данные файла теперь читаются из mpv на `FileLoaded`, а очищаются только при переходе в простой
- В режиме разработки файл из командной строки открывался дважды (StrictMode) — обрабатывается один раз
- «Продолжить с 0:23:14» на кнопке для часовой серии — теперь «23:14»
- Тесты: подмена Tauri иногда не срабатывала в общем прогоне — все команды и события теперь идут через `shared/ipc/bridge.ts`, тесты подменяют его; очистка DOM между тестами
