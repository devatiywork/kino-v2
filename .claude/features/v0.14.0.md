**Date:** 2026-10-24

### Added

- **«Назад» и «Вперёд» по истории страниц** во вкладке «Трекеры» (ТЗ 4.5):
  - работают через историю самого WebView2 (`GoBack` / `GoForward`), а не через `history.back()` в странице: между разными сайтами и независимо от скриптов страницы;
  - кнопка недоступна, когда идти некуда: ядро слушает событие WebView2 `HistoryChanged` и передаёт `canGoBack` / `canGoForward` в `trackers://state`;
  - мышь и клавиатура в самой странице (Alt+стрелки) работают как в обычном браузере.
- Ядро: `trackers/history.rs`. Доступ к контроллеру WebView2 идёт через `Webview::with_webview`; зависимости `webview2-com` 0.39 и `windows-core` 0.62 — те же версии, на которых собран wry, новых пакетов не скачивается.

### Changed

- **Никаких переходов в обычный браузер.** Ссылки на любые сайты открываются здесь же, во встроенном окне; ссылки «в новом окне» и `window.open` — на месте. В браузер по умолчанию страница уходит только кнопкой «Открыть в браузере». Перехват .torrent и magnet-ссылок, изоляция от Kino и запрет на страницы самого Kino и не-веб схемы остаются.
- «Открыть страницу раздачи» у торрента и записи архива открывает её во вкладке «Трекеры», какой бы сайт это ни был (раньше — только для сайтов из закладок).
- Закладка отмечается по сайту открытой страницы: ушли на другой сайт — отметка снимается, вернулись — появляется.
- Убраны событие `trackers://external`, строка «Другой сайт открыт в браузере» и правило «тот же сайт» в ядре (`rules::classify` больше не знает домашний сайт).
- ТЗ 4.5 обновлено под новое поведение.
- Тесты:
  - Rust — 76: правила переходов (любой сайт внутри, страницы Kino и чужие схемы закрыты).
  - Vitest — 88 + 132: доступность «Назад» / «Вперёд» по истории, отметка закладки по открытой странице, страница раздачи любого сайта — во вкладке.
  - E2E — 25. Фикстура трекера поднимает второй сайт на 127.0.0.2. Сценарий: ссылка на другой сайт открывается внутри, отметка закладки снимается, «Назад» → «Вперёд» → «Назад» между сайтами, «Вперёд» гаснет на последней странице.
  - Клик по ссылке через голый CDP идёт с `userGesture: true`: Chromium при «Назад» пропускает страницы, с которых ушли без действия пользователя.
