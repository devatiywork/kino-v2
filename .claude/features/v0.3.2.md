**Date:** 2026-10-23

### Added

- **ТЗ, раздел 4.5 «Трекеры — встроенное окно»** — искать раздачи, не уходя из Kino, без отдельных программ и без обхода защиты сайтов:
  - закладки трекеров (Рутрекер, RuTor и любые свои), сайт открывается внутри Kino со своими кнопками навигации
  - вход на сайт запоминается между запусками, капчу пользователь проходит сам
  - скачивание `.torrent` и magnet-ссылки перехватываются и сразу открывают окно добавления с категорией
  - ссылка на страницу раздачи сама записывается в архив
  - сайт трекера изолирован: у страницы нет доступа к данным и функциям Kino
- В архиве: повторное добавление того же торрента (тот же хеш) не создаёт дубль — «Уже в архиве»
- В предложения: свой поиск сразу по нескольким открытым трекерам (без капчи) по описаниям трекеров из Jackett

### Changed

- Kino — личный проект для одного пользователя, не для публикации:
  - в ТЗ и `CLAUDE.md` это записано явно; совместимость лицензий сторонних библиотек (GPL/LGPL-сборки mpv, описания трекеров Jackett) больше не ограничивает выбор
  - `license` в `package.json`: `UNLICENSED`
- «Вне рамок»: вместо «поиск раздач на трекерах» — «фоновый разбор сайтов трекеров и обход их защиты (капча, Cloudflare)»
- Раздел «Сеть» (теперь 4.7): к сайтам трекеров Kino обращается только пока открыто окно трекеров
- `CLAUDE.md`: окно трекеров в стеке и архитектуре Rust-ядра (изолированный WebView с постоянным профилем, перехват загрузок и `magnet:`), правило «удалённые страницы не получают доступа к IPC Tauri»
