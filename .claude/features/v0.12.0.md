**Date:** 2026-10-24

### Added

- **Торренты: движок, загрузки и архив** (ТЗ 4, 5):
  - **Движок.** librqbit 9 работает в ядре.
    - Быстрое продолжение: после перезапуска Kino торренты не перепроверяются целиком. Состояние движка и таблица DHT лежат в `<данные>\torrents\engine`.
    - Архив в SQLite — главный источник: при старте движок приводится к нему (лишнее убирается без удаления файлов, недостающее добавляется заново).
    - TCP и µTP, UPnP. Клиент представляется как «Kino 0.12.0».
  - **Добавление** (ТЗ 4.1):
    - Источники: .torrent кнопкой «Добавить торрент», перетаскиванием в окно или запуском с файлом (`kino-desktop.exe файл.torrent`, на будущее для «Открыть с помощью»); magnet-ссылка кнопкой «Magnet-ссылка», вставкой Ctrl V на экране загрузок или аргументом запуска.
    - У magnet-ссылки список файлов приходит от участников раздачи (ожидание до 90 с). Если такой торрент уже есть в архиве, его .torrent берётся оттуда, без сети.
    - Окно добавления: название, размер, хеш; категория (обязательна, по умолчанию последняя использованная) и «Новая категория» прямо в окне; папка (по умолчанию папка категории, можно ввести или выбрать); страница раздачи; «Начать сразу» (учитывает настройку); список файлов с флажками и «Все файлы».
    - Повторное добавление того же хеша не создаёт второй записи: окно говорит «Уже в архиве · категория · дата · статус» и предлагает «Открыть в загрузках», «Показать в архиве» или «Скачать снова».
  - **Загрузки** (ТЗ 4.3):
    - Список: имя, категория, число файлов, размер, пиры, прогресс с состоянием (проверка, загрузка, раздача, пауза, ошибка), осталось или рейтинг, скорости.
    - Пауза и продолжение — для одного торрента и для всех. Фильтр по категориям. Общие скорости в шапке.
    - Меню торрента: открыть папку, скопировать magnet-ссылку и хеш, открыть или указать страницу раздачи, сменить категорию, «Убрать из загрузок», «Удалить с файлами» (с подтверждением).
    - **«Смотреть»** (ТЗ 5): у торрента с полностью скачанным видеофайлом. Файл открывается в плеере; модули плеера и торрентов при этом друг друга не знают.
    - Многофайловый торрент получает свою папку внутри выбранной, как в qBittorrent.
  - **Панель подробностей** снизу (по образцу qBittorrent), высота меняется перетаскиванием или стрелками. Обновляется раз в секунду.
    - «Общее»: прогресс, передача, информация о торренте (части, кем создан, частный ли, даты, хеш, папка, комментарий, страница раздачи).
    - «Файлы»: флажки (снятые файлы не скачиваются), размер, прогресс, сколько осталось.
    - «Пиры»: адрес, соединение, клиент, скачано и отдано.
    - «Трекеры»: адреса трекеров; для частного торрента пояснение.
  - **Архив** (ТЗ 4.4):
    - В архиве каждый когда-либо добавленный торрент. Сам .torrent хранится внутри Kino (`<данные>\torrents\files\<хеш>.torrent`), удаление папки загрузок его не трогает.
    - Поиск по названию и именам файлов без учёта регистра, в том числе для кириллицы. Сортировка «Новые сначала» с группами по месяцам или «По имени». Фильтр по категориям.
    - Статусы: «В загрузках», «Файлы на диске», «Файлы удалены». Последний статус ставится и тогда, когда файлы удалили вручную.
    - Действия: «Скачать снова» в один клик (в прежнюю папку или в другую — та же запись, рейтинг сохраняется), «Снова раздавать» (файлы проверяются), «Удалить из архива» с подтверждением; ссылка на раздачу, magnet-ссылка, категория.
  - **Категории** (ТЗ 4.2): базовые «Сериалы», «Игры», «Программы». Свои можно создавать, переименовывать (правый клик по категории или «Изменить» в настройках), задавать им папку и удалять. Торренты удалённой категории переходят в «Без категории».
  - **Уведомления**: «Скачан» или «Скачан и убран в архив — файлы на месте».
- Настройки → раздел «Загрузки»:
  - папка по умолчанию (по умолчанию «Загрузки» Windows), категории и их папки;
  - «Не начинать загрузку сразу»;
  - «Не раздавать после загрузки — сразу в архив». При включении Kino спрашивает, убрать ли в архив то, что раздаётся сейчас (ТЗ 4.3);
  - лимиты загрузки и отдачи (кБ/с, применяются сразу).
- Ядро:
  - модуль `torrent` (engine, store, commands);
  - команды `torrent_*`, события `torrents://update` (раз в секунду), `torrents://changed`, `torrents://notice`;
  - миграция БД 4: `torrent_categories`, `torrent_items`, `torrent_files`;
  - общие команды `app_open_url` (только ссылки http/https) и `app_reveal_path` (показать файл в Проводнике).
- `KINO_TEST_OFFLINE` (только debug): торренты без сети — без DHT, трекеров, LSD и UPnP, только loopback, без запроса брандмауэра. E2E включают этот режим всегда.
- UI-библиотека 0.7.0:
  - `Checkbox` (с состоянием «выбрана часть»);
  - `TextField` (подпись, пояснение, ошибка, кнопка внутри поля);
  - у `Tabs` — `toolbar` (кнопки в строке вкладок) и `panelClassName`;
  - иконки Download, ArrowDown, ArrowUp, Magnet, Archive, Tag, Copy, External.
- Тесты:
  - Rust — 71. Среди них архив: категории, поиск без учёта регистра, запись не теряется при выходе из загрузок, повторная загрузка — та же запись. Движок: чтение .torrent и magnet. **Два движка на loopback**: один раздаёт, второй скачивает файл и сверяет байты, затем удаление с файлами.
  - Vitest — 106 + 88: форматы, хранилище торрентов, окно добавления (категория и папка, выбор файлов, дубли), действия с торрентом и архивом, экран загрузок (фильтр, подробности, вставка magnet-ссылки), `Checkbox`, `TextField`, `Tabs`.
  - E2E — 21. Новые сценарии:
    - .torrent из командной строки → окно добавления → уже скачанный файл проверяется и раздаётся → «Смотреть» открывает его в плеере;
    - «Убрать из загрузок» → «Снова раздавать» → «Удалить с файлами» (файл исчезает с диска) → «Скачать снова» — запись одна;
    - тот же .torrent после перезапуска — «Уже в архиве», торрент раздаётся дальше;
    - magnet-ссылка из архива узнаётся без сети;
    - «Не раздавать после загрузки» сразу отправляет в архив;
    - категории: создать, переименовать, удалить.
  - Генератор .torrent для тестов — `e2e/fixtures/torrent.ts`.

### Changed

- `now_ms` переехал в `db.rs`: дата нужна обоим разделам, а торренты не импортируют библиотеку плеера.
- Подмена моста Tauri в тестах (`test/tauriMock.ts`) теперь стоит и за `window.__TAURI_INTERNALS__`. Под нагрузкой Vitest иногда отдавал модулю настоящий мост вместо подменённого, и примерно в каждом втором полном прогоне падали два-четыре теста. Теперь любые вызовы попадают в мок.

### Fixed

- Уведомление «скачан» терялось, если интерфейс сразу после добавления читал список загрузок: это чтение тоже завершало торренты. Теперь завершает только фоновый цикл, а `torrent_list` только читает. «Убрать в архив то, что раздаётся» тоже ставит дату завершения.

### Not in this version

- Вкладка «Трекеры» (встроенный браузер с перехватом .torrent и magnet-ссылок), трей и работа в фоне, уведомления Windows.
- Регистрация Kino обработчиком `.torrent` и `magnet:` — вместе с установщиком.
- Резервная копия архива (экспорт и импорт), фильтр архива по датам.
- В подробностях: графики скорости, веб-источники, параметры отдельного торрента (свои лимиты, «до рейтинга», последовательная загрузка, суперсид), приоритеты файлов, карта частей.
- В настройках «Загрузок»: порт, прокси, шифрование, очередь, правила раздачи по рейтингу и времени, расписание лимитов.
