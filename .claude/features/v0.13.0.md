**Date:** 2026-10-24

### Added

- **Вкладка «Трекеры»** (ТЗ 4.5) — третья вкладка экрана «Загрузки», рядом с «Загрузки» и «Архив»: встроенный браузер для сайтов трекеров.
  - **Закладки** слева:
    - по умолчанию «Рутрекер» и «RuTor»;
    - «Добавить трекер»: достаточно адреса (`rutracker.org` превращается в `https://rutracker.org/`), название по умолчанию — имя сайта; новая закладка сразу открывается;
    - меню «…»: «Изменить», «Выше», «Ниже», «Удалить» (с подтверждением; вход на сайт и архив торрентов остаются);
    - вкладка открывается на трекере прошлого раза.
  - **Браузер** справа: «Назад», «Вперёд», «Обновить страницу» (крутится, пока страница грузится), адресная строка (Enter — перейти), пометка «Изолировано от Kino», «Открыть в браузере».
  - **Перехват .torrent.** Скачанный на трекере .torrent не попадает в «Загрузки» Windows: Kino сохраняет его в свою папку `<данные>\trackers\downloads` (чистится при запуске) и сразу открывает окно добавления.
    - Над окном пометка «перехвачено на <сайт>», поле «Страница раздачи» уже заполнено адресом страницы, где нажали «скачать». Ссылка уходит в архив вместе с торрентом.
    - Если такой торрент уже есть в архиве без страницы раздачи, запись получает ссылку с трекера.
  - **Перехват magnet-ссылок**: клик по magnet открывает окно magnet-ссылки и сразу спрашивает пиров. Торрент из архива узнаётся без сети. Страница раздачи сохраняется, даже если пиры не ответили и ссылку отправили повторно.
  - **Чужие сайты.** Ссылка на другой сайт открывается в браузере по умолчанию, страница трекера остаётся на месте. Ссылка «в новом окне» на том же сайте открывается здесь же. Над страницей появляется строка о том, что сделал Kino («Kino перехватил .torrent — в «Загрузки» Windows ничего не сохранено», «Другой сайт открыт в браузере: …»).
  - **«Открыть страницу раздачи»** у торрента и записи архива: страница трекера из закладок открывается во вкладке «Трекеры», другого сайта — в браузере.
- **Изоляция.** Сайт трекера не получает доступа к Kino:
  - у удалённых страниц нет ни одной команды Tauri и ни одного плагина: в capabilities нет `remote.urls`, вызовы отвергаются как «not allowed» (проверено в E2E, в том числе подделка события `trackers://torrent`);
  - переходы на страницы самого Kino (`tauri.localhost`, адрес Vite в разработке, `localhost`) и на схемы кроме http/https/magnet запрещены;
  - вход на сайт и капча — как в обычном браузере. Cookies живут в профиле WebView2 Kino и переживают перезапуск.
- Ядро:
  - модуль `trackers`:
    - `Trackers` — дочерний webview главного окна, положенный поверх вкладки по координатам из интерфейса;
    - `rules` — один ли это сайт (поддомены — тот же сайт; зоны вида co.uk), что разрешено, нормализация адреса; чистые функции с тестами;
    - `BookmarkStore` — закладки с порядком;
    - команды `tracker_*`, события `trackers://state`, `trackers://torrent`, `trackers://magnet`, `trackers://external`;
  - миграция БД 5: `torrent_bookmarks` с двумя закладками по умолчанию;
  - у Tauri включена функция `unstable` (несколько webview в одном окне).
- Интерфейс:
  - сущность `tracker` (закладки, адрес страницы, строка о перехвате, страница раздачи для вкладки, последняя закладка);
  - фича `manage-bookmarks` (`BookmarkList`, `BookmarkDialog`);
  - виджет `trackers-pane` (`TrackersPane`, `BrowserBar`, `useTrackerLayout`);
  - `shared/ipc/trackers` (с `siteKey`, повторяющим правило ядра);
  - `shared/lib/nativeLayer`: страница трекера — нативный слой поверх интерфейса, поэтому любой диалог над вкладкой (добавление торрента, magnet, закладка, подтверждение) на время прячет её.
- UI-библиотека 0.8.0: иконки Lock и Refresh.
- Тесты:
  - Rust — 77: правила сайтов и переходов, нормализация адреса, закладки (создание, порядок, перемещение, удаление).
  - Vitest — 88 + 133:
    - `siteKey`, хранилище трекеров;
    - список закладок: открыть, создать (ошибка ядра у поля), изменить, переставить, удалить; диалоги прячут страницу;
    - панель: последняя закладка, страница раздачи из загрузок, кнопки и адрес, скрытие под диалогом и при уходе с вкладки;
    - окно добавления с трекера; перехваты в `useCoreNotices`; «Открыть страницу раздачи» из архива.
  - E2E — 25. Новые сценарии против маленького трекера на loopback (`e2e/fixtures/trackerSite.ts`):
    - закладка → сайт → «скачать» → окно добавления с пометкой и страницей раздачи → запись в архиве со ссылкой, в «Загрузках» Windows файла нет;
    - «Открыть страницу раздачи» → вкладка «Трекеры» на этой странице; magnet того же торрента → «Уже в архиве»; другой сайт → строка, страница не уходит; новое окно → здесь же;
    - команды Kino со страницы трекера отвергнуты; вход на сайт и последний трекер после перезапуска на месте;
    - закладки: переименовать, переставить, удалить.
  - Фикстуры: `magnetOf` в `e2e/fixtures/torrent.ts`; `webPage` в `e2e/kino.ts` — страница браузера трекеров по адресу.

### Changed

- `openMagnetDialog(text, sourceUrl)` принимает ссылку и страницу раздачи; `submitMagnet` берёт страницу раздачи из состояния окна. `openTorrentFile(path, sourceUrl)` помечает торрент с трекера.
- E2E: `kino.ts` возвращает загрузки WebView2 из-под Playwright (`Browser.setDownloadBehavior: default`), иначе перехват .torrent в тестах не срабатывает.
