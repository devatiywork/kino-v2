**Date:** 2026-10-24

### Changed

- **Установщик ставит Kino v2 для всех пользователей, в `C:\Program Files\Kino v2`, с запросом прав администратора** — так же, как стоит Kino v1. Раньше установка шла только для текущего пользователя, без прав администратора, в `%LOCALAPPDATA%\Kino v2`. Выбранная вручную папка в Program Files давала ошибку «Невозможно открыть файл для записи …\kino-desktop.exe».
  - Регистрация в Windows — в `HKLM`, для всех учётных записей: типы файлов (видео, `.torrent`), `magnet:`, «Приложения по умолчанию» (`Software\KinoV2\Capabilities`), запись в списке программ. Ярлык — в общем меню «Пуск».
  - После установки Kino запускается от имени пользователя, а не администратора. Поэтому перетаскивание файлов из Проводника в окно работает.
  - Данные — по-прежнему у каждого пользователя свои, в `%APPDATA%\local.kino.app`. Галочка «Удалить данные приложения» в деинсталляторе чистит папку того, кто удаляет.

### Tests

- Код не менялся — только настройка сборки. Rust, Vitest и E2E не перезапускались: они проверяют отладочную сборку, а на неё режим установки не влияет.
- Установщик проверен по сгенерированному сценарию NSIS (`RequestExecutionLevel admin`, папка `$PROGRAMFILES64\Kino v2`, запуск после установки через `RunAsUser`) и по содержимому.
