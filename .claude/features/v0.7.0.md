**Date:** 2026-10-23

### Added

Первый этап самого приложения: `apps/desktop` (Tauri 2 + React 19), окно, главная и плеер на libmpv по рецепту из spike. Запуск — `bun run dev`.

- **Ядро на Rust** (`apps/desktop/src-tauri`):
  - `player/video_host.rs` — своё дочернее окно для видео внизу z-порядка, без `WS_CLIPSIBLINGS`; скрыто, пока не открыт экран плеера
  - `player/mod.rs` — libmpv в процессе: `gpu-next`, d3d11, аппаратное декодирование `auto-safe`, без чужих конфигов и скриптов, ввод и OSD mpv выключены (всё рисует страница), громкость до 130, внешние субтитры и озвучки рядом с видео подхватываются сами (`sub-auto`, `audio-file-auto`)
  - `player/events.rs` — поток событий mpv: наблюдает 16 свойств, держит снимок состояния и шлёт интерфейсу `player://state` при изменении и `player://position` не чаще 10 раз в секунду
  - `player/state.rs`, `player/tracks.rs` — снимок состояния и разбор `track-list` без типов libmpv, с тестами
  - команды: открыть, стоп, пауза, перемотка (абсолютная и относительная, точная), громкость, без звука, скорость, озвучка, субтитры, показ субтитров, подъём субтитров, показ окна видео; файлы из командной строки
- **Интерфейс** (Feature-Sliced Design):
  - заголовок окна: логотип, разделы, «Открыть», настройки, кнопки окна
  - главная — пока экран первого запуска: «Открыть файл» и перетаскивание (история и медиатека — со следующим этапом, им нужна база)
  - Сериалы, История, Загрузки, Настройки — заглушки «появится на следующих этапах»
  - перетаскивание видео в окно с подсказкой «Отпустите, чтобы открыть»; не видео — предупреждение
  - **плеер**: видео под прозрачной страницей; сверху «Назад» (ставит на паузу), название, кнопки окна; снизу прогресс (клик и перетаскивание, время под курсором), текущее время и «осталось / длительность», пауза, ±10 с, громкость с ползунком, «Озвучка и субтитры» (два списка с языком, кодеком, каналами и пометкой внешних), скорость 0.5×–2×, полный экран
  - панель скрывается через 2,5 с без мыши (не на паузе и не при открытом окне дорожек), курсор прячется
  - двойной клик — полный экран, колесо — громкость, сообщения поверх видео («Громкость 85», «Озвучка: …»)
  - горячие клавиши по физическим клавишам (работают и в русской раскладке): Пробел, ←/→, ↑/↓, F, Esc, M, S; в списках, меню и полях клавиши принадлежат им
  - субтитры mpv поднимаются над панелью, пока она видна (`sub-margin-y`)
  - русский и английский (i18next), тёмная тема
- **@kino/ui 0.4.0**: `PopoverButton` (кнопка со всплывающим окном произвольного содержания) и `TitleBarNav` (разделы в заголовке, значок с числом) — с тестами и в витрине
- Тесты: Rust — 11 (состояние, дорожки); Vitest — 37 в приложении (время, пути, роутер, названия дорожек, клавиши, перемотка, подъём субтитров; интеграционные — команды плеера через подменённый мост Tauri, синхронизация состояния с ядром, окно дорожек), 73 в UI-библиотеке
- Проверено в запущенном приложении (на сгенерированном тестовом ролике с внешней дорожкой и `.srt`): открытие из командной строки, видео под интерфейсом, окно дорожек, перемотка кликом, Пробел, стрелки, громкость, F и Esc, «Назад» прячет видео и ставит паузу

### Fixed

- Падение при запуске: `libmpv2` 6.0 в `create_client(Some(name))` отдаёт mpv уже освобождённую строку имени (временные значения в Rust 2024), mpv возвращает NULL, крейт его не проверяет. Клиент событий создаётся без имени
- Видео не появлялось в режиме разработки: StrictMode монтирует экран дважды, и запросы «показать / скрыть» обгоняли друг друга по IPC. Запросы пронумерованы, ядро игнорирует устаревший; скрытие откладывается на такт
- Vite следил за `src-tauri/target` и падал на заблокированном exe — папка исключена
