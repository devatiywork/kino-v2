**Date:** 2026-10-25

### Added

- **README** для GitHub (`README.md` в корне): что такое Kino, возможности плеера, медиатеки, торрентов, архива и трекеров, горячие клавиши, установка, приватность, сборка из исходников, устройство, сторонние компоненты и их лицензии.
- **Скриншоты** в `docs/screenshots` (WebP): главная, библиотека, загрузки с идущей загрузкой, архив, настройки загрузок.
- **Как их переснять** — `apps/desktop/e2e/readme`:
  - `demo-media.ts` — демо-медиатека: сериалы и фильмы из сгенерированных ffmpeg картинок (фракталы в палитрах magma, inferno и viridis, градиенты с размытыми пятнами света), с беззвучными дорожками «Дубляж» и «Original» и своими субтитрами. Названия выдуманы, чужих прав нет. 12-секундный клип зацикливается без перекодирования до длины настоящей серии или фильма;
  - `readme.e2e.ts` — съёмка с настоящего Kino на демо-медиатеке; без `KINO_README_MEDIA` и `KINO_LIBTORRENT_PYTHON` пропускается. Наполняет историю (открыть, перемотать, пауза — позиция и кадр сохраняются), добавляет раздачи и записи архива, а идущую загрузку второго сезона даёт сидер libtorrent на loopback. Окна скрыты, как в тестах: страницы снимаются через CDP, плеер — `window-shot.ps1`;
  - `window-shot.ps1` — снимок окна Kino через `PrintWindow`, с видео, даже если окно скрыто или под другими. Никогда не кусок экрана: туда попало бы чужое.
- `scripts/libtorrent-peer.py`: `LT_UPLOAD_LIMIT` — ограничение отдачи сидера; переподключение к пиру, пока соединения нет, для любой роли (первая попытка сидера могла прийти, пока он ещё проверял файлы).
- Метка «DEV» в заголовке отладочной сборки получила атрибут `data-dev-badge`: снимки для README её прячут.
