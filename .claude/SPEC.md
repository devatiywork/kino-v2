---

## 1. Что это

Kino — **видеоплеер и торрент-клиент** для Windows в одном окне. Делается для одного человека, не для публикации.

Две независимые части:

- **Плеер** — всё, что умел Kino 1, плюс главная с историей просмотра: какой сериал, какая серия, на какой секунде остановился.
- **Торренты** — качает что угодно (сериалы, игры, программы и т. д.) и **навсегда хранит архив всех торрентов** по категориям. Главная цель: через год скачать что-то снова в один клик, а не искать раздачу заново.

Части связаны слабо. Плеер не зависит от торрентов: у него своя медиатека и своя история просмотра, он работает и с файлами, скачанными где угодно. Из торрента с видео можно открыть плеер (раздел 5).

---

## 2. Окно и навигация

- Свой заголовок окна, кнопки «свернуть / развернуть / закрыть» справа, как в Windows.
- Разделы в заголовке: **Главная** · **Сериалы** · **История** · **Загрузки**. Настройки — кнопкой справа.
- Внутри «Загрузок» — вкладки **Загрузки** · **Архив** · **Трекеры**.
- Поиск в заголовке (Ctrl K) ищет по истории, медиатеке и архиву торрентов.
- Оформление «Проектор»: тёмная тема (по умолчанию), светлая, «как в системе». Видео и элементы поверх него всегда тёмные.
- Перетаскивание в окно: видео или папка — открыть в плеере; `.torrent` — добавить торрент (раздел 4.1).

## 3. Плеер

### 3.1 Воспроизведение (как в Kino 1)

- Любые форматы: mkv, mp4, avi, ts, m2ts, mov, webm и другие — всё, что умеет mpv.
- Мгновенная смена озвучки и субтитров без перезагрузки видео. ASS/SSA со стилями, SRT, PGS.
- Скорость 0.5× / 0.75× / 1× / 1.25× / 1.5× / 2×. Громкость колесом мыши.
- Панель управления скрывается через 2.5 с без движения мыши: появление 200 мс, скрытие 300 мс.
- Прогресс-бар: перемотка кликом и перетаскиванием, таймкод при наведении.
- Полный экран: F, двойной клик; Escape — выход.
- Горячие клавиши (переназначаются в настройках):

| Действие             | Клавиша |
| -------------------- | ------- |
| Пауза / воспроизвести | Пробел |
| ±10 секунд           | → / ←   |
| Громкость ±          | ↑ / ↓   |
| Полный экран         | F       |
| Следующая / предыдущая серия | N / P |
| Субтитры вкл/выкл    | S       |

### 3.2 Главная и история

- **Продолжить** — последнее, что смотрели, с кадра и секунды остановки.
- **Не досмотрено** — карточки с прогрессом и оставшимся временем.
- **История** по дням: время, сериал, серия, «досмотрено» или «остановились на 23:14».
- **Сериалы и папки** — прогресс по сезону полосками серий.
- При открытии файла воспроизведение продолжается с места остановки, сверху сообщение «Продолжено с 23:14 · Начать сначала».
- Серия считается просмотренной после 90%.

### 3.3 Сериалы

- Сезоны и серии раскладываются по именам файлов (S02E05, 2x05, «Серия 5»), сортировка естественная: 2 перед 10.
- Автовоспроизведение следующей серии; в конце сезона — остановка.
- **Память дорожек для сериала**: выбранные озвучка и субтитры применяются к следующим сериям.
  - Подбор только по языку и названию дорожки, **никогда по номеру**.
  - При смене файла дорожки сбрасываются, предпочтения применяются только после загрузки списка дорожек нового файла.
  - Совпадения нет — включается первая дорожка и показывается уведомление: «Дорожка "LostFilm" не найдена, выбрана: English».
- **Освободить место**: удалить файлы досмотренного сезона. История и прогресс остаются. Если сезон был скачан торрентом, на странице сериала появляется «Скачать снова» (раздел 5).

## 4. Торренты

### 4.1 Добавление

- Источники: `.torrent` файл (кнопка, перетаскивание, двойной клик в Проводнике), magnet-ссылка (кнопка, вставка из буфера, клик по ссылке в браузере). Kino регистрируется обработчиком `.torrent` и `magnet:`.
- Окно добавления:
  - название и общий размер;
  - **категория** — обязательна, по умолчанию последняя использованная;
  - папка сохранения — по умолчанию папка категории, можно поменять;
  - список файлов с галочками — можно скачать не всё;
  - ссылка на страницу раздачи — необязательно, но полезно для архива;
  - «Начать сразу».

### 4.2 Категории

- Базовые: **Сериалы**, **Игры**, **Программы**.
- Свои категории можно создавать, переименовывать и удалять. У категории есть название и папка сохранения по умолчанию.
- При удалении категории её торренты переходят в «Без категории», ничего не теряется.

### 4.3 Загрузки

- Список активных торрентов: название, категория, прогресс, скорость ↓/↑, осталось времени, сиды и пиры, рейтинг раздачи.
- Пауза и продолжение — для одного торрента и для всех.
- Фильтр по категориям.
- Меню торрента (кнопка «…» и правый клик): открыть папку, скопировать magnet, страница раздачи, категория, убрать из загрузок, удалить с файлами.

**Подробности выбранного торрента** — панель снизу, по образцу панели свойств qBittorrent. Высота меняется перетаскиванием верхнего края.

- **Общее**:
  - полосы «Скачано» (карта частей) и «Доступность» (насколько части есть у пиров);
  - передача: время активности, осталось, соединения (и лимит), скачано и отдано (и за сессию), сиды и пиры (подключено и в сети), скорости (и средние), лимиты, потеряно, рейтинг, переобъявление через, популярность;
  - информация: размер, части, чем создан, частный ли, даты добавления, завершения и создания, категория, хеши v1 и v2, папка, комментарий, страница раздачи.
- **Трекеры**:
  - сначала DHT, PeX и LSD, потом трекеры торрента;
  - колонки: уровень, протокол, статус, пиры, сиды, личи, скачали, сообщение, следующий запрос, минимальный интервал;
  - у частного торрента DHT, PeX и LSD отключены, это видно в таблице;
  - действия: добавить трекеры, переобъявить; по правому клику — скопировать, изменить адрес, удалить.
- **Пиры**:
  - колонки: страна, адрес, порт, соединение (BT или µTP), флаги, клиент, прогресс, скорости ↓ и ↑, скачано, отдано, значимость, файлы;
  - под таблицей расшифровка флагов;
  - добавить пиры; по правому клику — скопировать адрес или заблокировать.
- **Веб-источники**: HTTP-зеркала торрента, можно добавить своё.
- **Файлы**: галочки, размер, прогресс, приоритет (не загружать, обычный, высокий, максимальный), осталось, доступность, «выбрать все» и «снять все».
- **Скорость**: график загрузки и отдачи за 1, 5 и 30 минут.
- **Параметры торрента**:
  - лимиты загрузки и отдачи, максимум соединений;
  - раздача: как в настройках, до рейтинга или не раздавать;
  - загружать последовательно, сначала первые и последние части, суперсид;
  - переместить файлы, сменить категорию;
  - проверить файлы, переобъявить трекерам, сохранить `.torrent`, скопировать magnet и хеш.

### 4.4 Архив торрентов — главная фишка

- **Каждый когда-либо добавленный торрент хранится навсегда**, даже если его убрали из загрузок и удалили файлы:
  - сам `.torrent` (или magnet-ссылка, если файла не было);
  - хеш, название, размер, список файлов;
  - категория, папка сохранения;
  - даты добавления и завершения;
  - ссылка на страницу раздачи, если указали.
- `.torrent` хранится внутри данных Kino, а не в папке загрузок: удаление папки ничего не теряет.
- Удаление — три разных действия:
  - **Убрать из загрузок** — файлы и запись в архиве остаются;
  - **Удалить с файлами** — запись остаётся с пометкой «файлы удалены»;
  - **Удалить из архива** — полностью, только с подтверждением.
- Архив: поиск по названию и файлам, фильтр по категориям и датам.
- **Скачать снова** — в один клик, в прежнюю папку или в другую.
- Повторное добавление того же торрента (тот же хеш) не создаёт дубль: Kino показывает «Уже в архиве — категория, дата, статус» и предлагает скачать снова или открыть запись.
- Резервная копия: экспорт всего архива (`.torrent` + описание) в один файл и импорт обратно.

### 4.5 Трекеры — встроенное окно

Искать раздачи, не уходя из Kino, без отдельных программ и без обхода защиты сайтов.

- Вкладка **Трекеры** с закладками сайтов: Рутрекер, RuTor и любые другие. Закладки можно добавлять, переименовывать, удалять и менять местами.
- Сайт трекера открывается прямо внутри Kino. Над ним — свои кнопки: назад, вперёд, обновить, адрес страницы, «открыть в браузере».
- Вход на сайт запоминается между запусками. Капчу, если сайт её показывает, пользователь проходит сам — как в обычном браузере.
- Нажатие на скачивание `.torrent` или на magnet-ссылку перехватывается: файл не уходит в «Загрузки» Windows, сразу открывается окно добавления (раздел 4.1) с выбором категории.
- **Ссылка на страницу раздачи записывается в архив автоматически.**
- Если такой торрент уже есть в архиве — сразу видно «Уже в архиве», без повторного добавления.
- Ссылки, ведущие с трекера на другие сайты, открываются в браузере по умолчанию.
- Сайт работает изолированно: у страницы трекера нет доступа к данным и функциям Kino.

### 4.6 Работа в фоне

- Если при закрытии окна идут загрузки или раздачи — Kino сворачивается в трей (настраивается).
- Значок в трее: общая скорость, пауза всех, открыть, выйти.
- Уведомление Windows, когда торрент скачан.

### 4.7 Сеть

- При первом запуске брандмауэр Windows спросит разрешение на входящие подключения.
- Пока идёт раздача, IP-адрес виден другим участникам.
- Kino обращается в сеть только по протоколу BitTorrent, к сайтам трекеров — только пока открыто окно трекеров, и к проверке обновлений, если её включить.
- Kino не ходит по сайтам трекеров в фоне и не обходит их защиту (капча, Cloudflare).

## 5. Связь плеера и торрентов

- У торрента с видео — кнопка **Смотреть**: файлы открываются в плеере, папка попадает в медиатеку.
- История просмотра живёт в плеере, торрент о ней не знает.
- Если файлы сериала удалены, а торрент есть в архиве, на странице сериала — **Скачать снова**.
- Повторно скачанный торрент узнаётся по хешу: серии встают на место, прогресс и запомненные дорожки сохраняются.

## 6. Настройки

- **Внешний вид**: тема, акцентный цвет, язык (русский, английский).
- **Воспроизведение**: продолжать с места остановки, автовоспроизведение, карточка «Далее», скорость и громкость по умолчанию, аппаратное декодирование.
- **Озвучка и субтитры**: предпочитаемая озвучка, субтитры при русской озвучке, размер и позиция субтитров.
- **Библиотека и история**: вести историю, порог «просмотрено», папки сериалов, очистить историю.
- **Загрузки** (по образцу параметров qBittorrent, без редкого — почты, I2P, RSS):
  - *добавление и папки*: окно добавления, не начинать сразу, папка по умолчанию, категории и их папки, отдельная папка для недокачанного, удалять исходный `.torrent` после добавления (копия остаётся в архиве), тот же торрент ещё раз — объединить трекеры, выделять место заранее;
  - *скорость*: лимиты загрузки и отдачи, альтернативные лимиты и расписание для них (каждый день / будни / выходные), лимиты для µTP и для локальной сети;
  - *соединение*: протокол (TCP и µTP), порт для входящих (случайный, проверка), UPnP / NAT-PMP, соединения и слоты отдачи (всего и на торрент), сетевой адаптер (привязка к VPN), прокси;
  - *BitTorrent*: DHT, PeX, LSD (у частных торрентов выключены сами), шифрование (разрешить / требовать / отключить), анонимный режим, очередь (активных загрузок, раздач, всего; медленные не считаются), остановка раздачи по рейтингу или времени и что делать потом (остановить, убрать из загрузок, суперсид), свои трекеры к новым загрузкам;
  - *поведение*: при закрытии окна — в трей или выйти, уведомления о завершении, не засыпать во время загрузок, Kino как обработчик `.torrent` и `magnet:`.
- **Горячие клавиши**: таблица, переназначение кликом и нажатием клавиши.
- **Система**: открывать видео через Kino, одно окно, медиаклавиши, не давать компьютеру засыпать во время просмотра, обновления.
- Все изменения применяются сразу, без кнопки «Сохранить». «Сбросить настройки» — с подтверждением.

## 7. Данные

- Одна база SQLite в папке данных приложения (`%APPDATA%`), два независимых раздела:
  - **плеер** — медиатека, файлы, позиции, история, предпочтения дорожек;
  - **торренты** — категории, архив торрентов (с самими `.torrent`), файлы торрентов, состояние загрузок.
- Связь между разделами — только необязательная ссылка «этот видеофайл пришёл из этого торрента».
- Всё хранится только на этом компьютере. Облака и синхронизации нет.

## 8. Вне рамок

- Онлайн-стриминг, YouTube, Twitch.
- Фоновый разбор сайтов трекеров и обход их защиты (капча, Cloudflare). Трекеры открываются только во встроенном окне (раздел 4.5).
- Установка кодеков и драйверов.
- Облачная синхронизация и удалённые библиотеки.
- Мобильные и веб-версии.
- Телеметрия, аналитика, отчёты о сбоях.
- Воспроизведение контента с DRM.
- Редактирование и конвертация видео.

## 9. Предложения на согласование

Не делать без подтверждения.

**Плеер**
- Пропуск заставки: кнопкой или автоматически, по главам файла.
- Карточка «Далее» с обратным отсчётом в конце серии.
- Автопоиск внешних `.ass`, `.srt`, `.mka` рядом с видео и в папках вроде `Subs/`, `RUS Sound/`.
- Сдвиг субтитров клавишами Z / X.
- Превью кадра при наведении на прогресс-бар.
- Громкость выше 100% и ночной режим звука.
- Мини-плеер поверх всех окон.
- Медиаклавиши и плашка Windows с названием серии.

**Торренты**
- Четвёртая базовая категория **Фильмы**.
- Кнопка «Смотреть» сразу включает последовательную загрузку, чтобы первую серию можно было начать до конца закачки (сам параметр «Загружать последовательно» уже есть в 4.3).
- Притормаживать отдачу во время просмотра видео (до 100 КБ/с).
- Следить за папкой «Загрузки» браузера и добавлять оттуда новые `.torrent` с окном выбора категории.
- Импорт архива из qBittorrent (его `.torrent` и папки сохранения).
- Заметка к торренту: «пароль от архива», «ставить с галочкой X» и т. п.
- Свой поиск в интерфейсе Kino сразу по нескольким трекерам — для тех, что открываются без капчи. По готовым описаниям трекеров из проекта Jackett.
